# Embedded PDF fonts

`NotoSansSC-Static.ttf` is a static 400-weight subset covering Latin, common
punctuation, full-width punctuation, and the CJK Unified Ideographs ranges from
the Noto Sans CJK SC variable font distributed by Google under the SIL Open
Font License, Version 1.1. It is bundled as a static TrueType face because
PDFBox requires static outlines for reliable CJK text extraction.

Source: <https://fonts.google.com/noto/specimen/Noto+Sans+SC>
License text: <https://scripts.sil.org/OFL>

The files are bundled so PDF output does not depend on fonts installed on the
host operating system.
