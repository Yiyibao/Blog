# ADR-003：年度容量门与单实例架构保留

- 状态：Accepted（年度本地验收；生产容量数据待补）
- 日期：2026-08-13
- 范围：M12 年度灾备、性能与扩容决策

## 决策

继续采用 nginx 静态前端 + 单实例 Spring Boot + PostgreSQL + 受控本地存储。保留进程内登录限流、挑战冷却、AI 有界并发和既有缓存；本年度不引入 Redis、多实例或独立 AI worker。

## 依据

- 当前部署约束明确要求后端单副本；登录限流和认证冷却使用进程内状态。
- AI 任务已有全局/用户/provider 有界并发与队列上限，菜谱异步作业已有数据库 lease/heartbeat；未观察到需要扩容的生产吞吐证据。
- 本地恢复演练 RTO 为 8.8 秒，公开/后台目标和告警阈值已写入 `docs/observability-slo.md`，但本次没有生产 API/AI p95、任务 SLA、内存或存储增长样本。

## 扩容触发条件

当生产连续观测到连接池 pending > 0 或 active/max ≥ 0.8、AI 队列持续增长/任务 p95 超过 60 秒、公开 API p95 ≥300ms、后台 API p95 ≥500ms、5xx ≥0.5%，或需要第二个后端副本时，先将限流、缓存、任务 lease、SSE 事件和存储迁移为共享/外置状态，再评估 Redis、worker 和多实例；不直接横向复制当前进程。

## 后果

架构保持小而可恢复，避免没有共享状态方案的伪扩容。生产上线前仍必须取得真实监控数据并重新评估本 ADR。
