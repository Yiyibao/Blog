# 评论与公开协作功能安全门禁

路线图明确建议评论系统暂缓。本项目在以下条件全部具备前不开放匿名或公开评论写入口：

1. 审核：先审后发/敏感内容复核、管理员操作审计和误删恢复；
2. 反垃圾：账号与 IP 双层限流、人机验证、重复内容和链接频率控制；
3. 用户安全：举报、屏蔽、封禁、申诉和骚扰处置流程；
4. 隐私：最小化保存 IP/设备信息，明确保留期限、导出和删除机制；
5. 权限：作者、协作者、审核员、管理员的最小权限矩阵；
6. 运维：异常量告警、备份恢复、数据迁移和紧急关闭开关；
7. 测试：越权、XSS、CSRF、刷屏、并发审核和隐私删除回归测试。

当前的 `ADMIN` / `PARTNER` 角色协作继续使用既有受保护后台能力。评论功能只有在上述策略、数据模型、接口契约和运营责任人共同评审通过后再单独立项。
