# 全站知识关联图谱 V2 实施方案

## 目标

把归档页现有的普通 SVG 关系图升级为“花园式知识图谱”：以全站知识为中心，文章、学习笔记、美食菜谱、合集、标签形成五个彩色枝系；保留真实语义关系，同时增加轻微、自然、可关闭的动画和完整的键盘/触屏交互。

参考图只作为视觉方向，不逐像素复制。实际实现需要适配现有站点字体、明暗主题、移动端和真实数据量。

## 信息架构

画布分为三层：

1. `ROOT`：唯一中心节点“全站知识”。
2. `GROUP`：文章、学习笔记、美食菜谱、合集、标签五个分类枢纽。
3. `CONTENT`：真实内容节点和标签节点。

关系分为：

- `STRUCTURE`：ROOT → GROUP → CONTENT，仅用于稳定聚类与花枝式布局。
- `RELATION`：现有真实关联，例如内容与标签、合集与文章；使用更细、低透明度或虚线表现。

后端不返回坐标。坐标属于前端视口和布局状态，服务端只返回稳定 ID、分组、权重、度数和关系强度。

## 后端契约

新增公开接口：

`GET /api/v1/graph/overview`

响应 `data`：

- `schemaVersion`: 当前为 `2.0`。
- `stats`: 内容节点数、视觉节点数、真实关系数、最近更新时间、推荐中心节点、是否建议自动进入局部模式。
- `legend`: 类型、中文名称、固定色值、数量。
- `nodes`: `id/label/type/kind/groupId/url/subtitle/imageUrl/updatedAt/degree/importance`。
- `edges`: `source/target/kind/strength`。

保留兼容接口：

- `GET /api/v1/graph/nodes`
- `GET /api/v1/graph/nodes/{center}?depth=1..3`

旧节点响应增加了可选的 `subtitle/imageUrl/updatedAt` 字段，旧客户端忽略额外字段即可。

## 后端实现

- 文章投影增加发布日期，笔记和菜谱投影增加更新时间，菜谱投影增加图片地址。
- 合集直接复用已有封面和更新时间。
- `GraphService.toOverview` 从已缓存的语义图生成视觉图，不重复查询数据库。
- ROOT/GROUP 为虚拟节点，不写入数据库。
- 内容重要度由真实关系度数确定，避免前端各自推导出不一致的节点大小。
- 图例颜色由契约固定，保证首次渲染和服务端数据一致。
- 超过 300 个真实节点时返回 `localModeRecommended=true`，并给出最高连接度的推荐中心。
- 游客继续看不到学习笔记节点、笔记枢纽及相关边；登录后沿用原权限逻辑。

## 前端布局建议

- 使用现有 Vue 3 + TypeScript，不新增重量级图谱依赖。
- SVG 负责边、节点和文本；HTML overlay 负责图例、统计、工具栏、搜索、详情卡和缩略导航。
- 布局分两段：先按固定扇区计算 GROUP 锚点，再在组内使用确定性极坐标/轻量碰撞迭代。
- 使用节点 ID 作为伪随机种子，刷新后布局稳定；禁止 `Math.random()` 直接参与最终坐标。
- ROOT 居中，五个 GROUP 使用预设角度；移动端改成可横向浏览的紧凑布局。
- 菜谱 `CONTENT` 节点有 `imageUrl` 时使用圆形裁切缩略图，其余使用类型图标。

## 动画与交互

- 首次进入：ROOT、GROUP、CONTENT 分三段错峰淡入，总时长控制在 700–1100ms。
- 节点呼吸：仅 GROUP/ROOT，缩放幅度不超过 1.025，周期 4–7 秒且不同相位。
- 枝叶漂移：仅装饰层，位移 1–3px；不改变真实节点命中区域。
- 边流动：只对当前 hover/selected 的关联边显示低速 dash offset。
- 拖动画布使用 Pointer Events；滚轮/触控板以鼠标点为中心缩放。
- hover 高亮一跳邻居；单击锁定选择并显示详情；双击沿用两层子图；Esc 清除选择。
- 搜索匹配标题、副标题和类型；结果按 `importance`、前缀匹配和更新时间排序。
- 工具栏提供放大、缩小、复位、刷新布局、全屏。
- 小地图只在宽度充足时展示；视口矩形可拖动。
- `prefers-reduced-motion: reduce` 时关闭呼吸、漂移、描线和错峰动画，只保留即时状态变化。

## 性能边界

- 节点 ≤ 300：完整图。
- 节点 > 300：优先使用后端推荐中心加载局部子图，提供“返回全图”。
- 拖拽期间只更新 transform，不重新计算节点。
- hover 邻接表预计算，避免每次扫描全部边。
- SVG 文本按缩放级别分级显示；低缩放仅显示 ROOT/GROUP 和选中节点。
- 使用 `requestAnimationFrame` 合并 pointermove，组件卸载时释放监听器和动画帧。

## 验收

- 数据：图例计数、真实关系数、最近更新时间与接口一致。
- 权限：游客响应不含任何 NOTE 节点或 `hub-note`。
- 视觉：ROOT 居中、五类成簇、结构边和关系边可区分、菜谱图片正常裁切。
- 交互：缩放、平移、复位、全屏、搜索、选择、跳转、子图、返回全图均可用。
- 动效：自然轻微，无持续高频重排；低动态偏好下完整降级。
- 可用性：键盘可聚焦节点和工具按钮，状态区具备 `aria-live`。
- 测试：原有 KnowledgeGraph 测试不回退，新增 overview API、布局稳定性、搜索、reduced-motion 和清理监听器测试。
