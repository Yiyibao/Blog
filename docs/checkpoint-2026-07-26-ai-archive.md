# AI 与归档体验检查点（2026-07-26）

## 本轮目标

增加管理员 DeepSeek AI 对话能力，提供 JetBrains IDE 一键启动配置，并重构公开归档、知识关联图谱和后台导航体验。

## 管理员 AI 对话

- 新增管理员路由 `/admin/ai`，沿用现有 JWT 管理权限。
- 前端支持最多 20 条临时消息、8,000 字单条输入、会话级存储、清空和错误状态。
- 模型输出按不可信纯文本渲染，不使用 `v-html`。
- 后端新增 `POST /api/v1/admin/ai/chat`，直接调用 DeepSeek 官方 Chat Completions API。
- 默认模型为 `deepseek-v4-flash`，关闭 thinking、流式输出和工具调用。
- API Key、模型和基础地址只从后端环境变量读取，不暴露给浏览器。
- AI 默认关闭；未配置或不可用时不影响博客其他功能。
- 增加输入长度、消息数量、累计字符数、超时和上游错误映射测试。

启用所需的最小本地配置：

```properties
AI_ENABLED=true
AI_API_KEY=replace_with_your_deepseek_api_key
```

## IDE 一键启动

- 新增 `.run/Backend.run.xml`，从 `backend` 目录执行 `spring-boot:run`。
- 新增 `.run/Frontend.run.xml`，从 `frontend` 目录执行 `npm run dev`。
- 新增 `.run/Full Stack.run.xml`，在 JetBrains IDE 中同时启动前后端。
- 联合运行配置名称为 `BlogDemo - Full Stack`。

## 归档与知识图谱

- 归档页提供“时间轴 / 关联图”互斥视图。
- 视图、内容类型和关系筛选与 URL 查询参数同步。
- 将持续运动的 Canvas 图谱改为确定性 SVG 布局，移除随机位置和永久动画循环。
- 节点首次点击只选中并展示详情，明确点击“打开内容”后才导航。
- 标签节点只用于关系筛选，`url` 固定为 `null`，不再链接已删除的分类页面。
- 图谱类型筛选保留相关标签中心，并对节点数量进行内容与标签平衡限制。
- 点击区域至少 44×44px，支持键盘操作、错误状态、空状态、移动端布局和减少动效偏好。
- 后端使用稳定的 Unicode 标签哈希 ID，忽略空关系、去重边并确定性排序输出。

## 后台导航

- 每次只高亮一个入口，删除手工固定高亮和 hover 位移动画。
